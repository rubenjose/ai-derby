Check a race

Each race has a record: the file the film was made from. It holds every question, every answer exactly as the model wrote it, how each answer was marked, and the settings the race ran under. Beside each race is the record's fingerprint, a SHA-256 of the file. Change one character of a record and its fingerprint changes.

"Check it" fetches the record and works the fingerprint out in your browser. To do it yourself, download the record and run:

shasum -a 256 creative.json

To check without trusting this page, compare the result with the fingerprint in the film's description on YouTube, or with the history of the records, which shows when each was published and that none has changed since.

What this proves, and what it does not. It proves the record you read today is the one published with the film. It does not, by itself, prove the models gave those answers. For that, the small models are public: the record names each model file and its settings (temperature 0), so the same questions can be put to the same model again.

How a race is timed. Each fence takes 6.5 s plus up to 0.3 s of pace, from how much the horse wrote. A stumble (a near miss) costs 4 s and a fall (a big miss, or no readable answer) 8 s. 3 falls and a horse is out. Equal times are a dead heat. The caller is a computer voice reading a script written from the race's events.
